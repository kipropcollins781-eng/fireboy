# Fireboy

A demo casino / real-money gaming application structure.

## Project structure

```text
fireboy/
├── backend/
│   ├── server.js
│   ├── package.json
│   └── routes/
│       └── games.js
├── frontend/
│   ├── index.html
│   └── README.md
├── README.md
├── .gitignore
└── .gitkeep
```

## Backend setup

```bash
cd backend
npm install
npm start
```

The API will run on http://localhost:3000
